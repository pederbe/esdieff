# Architecture decisions

Each record explains one decision behind Esdieff's behaviour: the question, the
options considered and the consequences accepted. Records are numbered in the
order they were made and are never rewritten. A later record supersedes an
earlier one when a decision changes.

The [domain language](../../GLOSSARY.md) defines the terms these records use.

Records describe decisions at the time they were made. For current command
options, report versions and support boundaries, use the [guides and reference
contracts](../README.md). Later records can extend a decision while earlier
records retain their original implementation-stage wording.
