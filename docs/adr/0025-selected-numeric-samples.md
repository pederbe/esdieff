## Considered Options

Reacquiring a sample through a second catalogue would obscure joint limits and source identity. Reusing original-source views for generated projections would invent byte provenance. Broad selected-model validation followed by diagnostic filtering would spend work and create findings for unrequested context. Resetting numeric work for each constraint would ignore input parsing and allow repeated obligations to evade the limit. Converting numbers to a machine float or appending exponent-sized zero buffers would change exactness or resource guarantees. A separate sample report would duplicate the shared outcome, scope and presentation contracts without a needed domain boundary.
