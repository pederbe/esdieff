# Triage labels

Use these label strings when a skill refers to a triage role.

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified for implementation; priority is decided separately. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be implemented. |

Edit the Label column if the repository's label vocabulary changes.
