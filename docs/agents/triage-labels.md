# Triage labels

These labels describe an issue's state.

| Label | Meaning |
| --- | --- |
| `needs-triage` | The maintainer needs to evaluate the issue. |
| `needs-info` | Waiting for information from the reporter. |
| `ready-for-agent` | Fully specified for implementation. Priority is decided separately. |
| `ready-for-human` | Requires human implementation. |
| `wontfix` | Will not be implemented. |
