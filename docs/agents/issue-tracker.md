# Issue tracker

[GitHub Issues](https://github.com/pederbe/esdieff/issues) holds bug reports,
feature requests, public specs and implementation tickets.

Follow the [public issue and pull request rules](../../CONTRIBUTING.md#public-issues-and-pull-requests).
Use the template's existing sections. Keep technical results and relevant links
within them, with checklists, linked issues and labels for progress.
Keep working notes and handoffs private.
