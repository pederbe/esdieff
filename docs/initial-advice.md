# Initial contradiction advice

Esdieff explains four kinds of [constraint contradiction](../GLOSSARY.md) in established effective Full Data Descriptions. Each proven contradiction produces warning advice with a stable `proof.*` code and `assessment_unit:"advisory-four/1"`. This follows [ADR 0003: Check findings and completeness](adr/0003-check-findings-and-completeness.md), [ADR 0009: Bounded processing and reporting](adr/0009-bounded-processing-and-reporting.md), and [ADR 0013: Shared workflow and report guarantees](adr/0013-shared-workflow-and-report-guarantees.md).

For example, `type:"number", nullable:false, minimum:2, exclusiveMaximum:2` admits no numeric value. The warning explains the conflicting effective bounds, their nearest source contributors and the importing reference when present. Composition repairs and deletions are applied before proofs; the original source bytes remain available.

A nonnull wrong primitive kind is independent of nullable; const null contradicts nullable false, including with known string formats. Array/map constants and array/map base types are excluded. |

Owners with enum or sdfChoice are excluded, including malformed selectors. Established derived alternatives and nested full properties have their own guards. Direct item descriptions themselves are excluded; inheriting a direct-item quality into a Full alternative does not establish a meaning that was unavailable in its donor. The [effective alternatives contract](adr/0024-effective-alternatives-and-nullable-characteristics.md) preserves these distinctions.

Recognized abstract formats alone do not establish nonnull primitive const compatibility from a conventional JSON representation. Acquisition spends numeric work across all supplied sources. Each check starts one counter from the immutable remaining acquisition budget and shares it across descriptions, inherited instances, classes and pairs. Exact comparison charges the longer normalized coefficient length plus one before comparing. Integrality premises charge one unit each. Exponent gaps do not allocate expanded numbers, and normalized powers do not reapply raw exponent limits. Independent nonnumeric proofs can still warn. Repeating a check uses the same immutable acquisition remainder.
